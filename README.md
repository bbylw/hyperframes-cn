## ✨ 站点特性与核心升级

- **🎬 电影工业级设计系统**：暗黑胶片美学、琥珀流金高光、全套高精度 1.75px 矢量 SVG 图标体系。
- **⚡ 实时渲染工坊 (Live Playground)**：支持 5 款工业级预设场景（产品发布短片、PR 讲解、图表竞速、逐字高潮字幕、动态排版），带交互式逐帧时间轴游标与即时预览。
- **🤖 AI 智能体提示词发生器 (Prompt Wizard)**：可视化配置需求，一键生成符合 Claude Code / Cursor / Codex 规范的智能体 Prompt 与 CLI 执行命令。
- **📚 20+ Skills 知识矩阵**：涵盖 `product-launch-video`、`cut-the-curve`、`motion-doctrine`、`embedded-captions` 等全套智能体技能检索与说明。
- **🚀 现代技术栈**：基于 **React 19 + TypeScript + Vite Plus + Bun** 构建，具备极速冷启动与高灵敏交互体验。

## 🛠️ 本地开发与体验

### 1. 安装依赖
```bash
bun install
```

### 2. 启动开发服务器
```bash
bun run dev
```

### 3. 代码检查与构建
```bash
# 规范与类型检查
bun run lint

# 生产环境打包
bun run build

# 本地运行打包产物
bun run serve
```
